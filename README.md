# 🗓️ Планировщик задач

Мобильное веб-приложение для планирования дня и недели: календарь до 2030 года,
задачи на день, цели на неделю, процент продуктивности недели (100% = идеальная неделя),
тёмная/светлая тема, 3 языка (RU/UK/EN), плавные анимации и собственный аватар.

Работает полностью локально — без сервера и базы данных. Все задачи хранятся
в памяти браузера на устройстве (localStorage). Это значит, что данные видны
только вам и не передаются никуда в интернет.

## Структура файлов

```
task-planner/
├── index.html          — главная страница приложения
├── css/style.css        — все стили и темы
├── js/i18n.js            — тексты интерфейса на RU/UK/EN
├── js/app.js             — логика приложения (календарь, задачи, статистика)
├── manifest.json         — настройки для установки как приложение
├── service-worker.js     — офлайн-режим
├── icons/icon-192.png    — иконка приложения
└── icons/icon-512.png    — иконка приложения (большая)
```

## 🚀 Как загрузить на GitHub

1. Зайдите на [github.com](https://github.com) и войдите (или зарегистрируйтесь).
2. Нажмите **New repository** (зелёная кнопка справа сверху или на `github.com/new`).
3. Задайте имя репозитория, например `task-planner`, и нажмите **Create repository**.
4. На странице нового репозитория нажмите **uploading an existing file**
   (или перетащите файлы прямо в окно браузера).
5. Перетащите **все файлы и папки** из этого проекта (сохраняя структуру —
   папки `css`, `js`, `icons` должны остаться папками).
6. Внизу страницы нажмите **Commit changes**.

### Включаем сайт (GitHub Pages)

1. В репозитории откройте вкладку **Settings**.
2. В меню слева выберите **Pages**.
3. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
4. В **Branch** выберите `main` и папку `/ (root)`, нажмите **Save**.
5. Подождите 1–2 минуты и обновите страницу — вверху появится ссылка вида:
   `https://ваш-ник.github.io/task-planner/`

Это и есть адрес вашего приложения — он будет работать с любого телефона и компьютера.

## 📱 Как установить на телефон

Откройте ссылку на сайт (`https://ваш-ник.github.io/task-planner/`) в браузере телефона.

**Android (Chrome):**
1. Откройте сайт в Chrome.
2. Нажмите на меню (три точки) в правом верхнем углу.
3. Выберите **«Добавить на главный экран»** (или **«Установить приложение»**,
   если Chrome предложит это сам баннером снизу).
4. Подтвердите — иконка появится на рабочем столе, как у обычного приложения.

**iPhone (Safari):**
1. Откройте сайт в Safari (именно в Safari, не в Chrome — iOS это требует).
2. Нажмите на значок **«Поделиться»** (квадрат со стрелкой вверх) внизу экрана.
3. Выберите **«На экран «Домой»»**.
4. Нажмите **«Добавить»** — иконка появится на экране.

После установки приложение открывается в полноэкранном режиме, без адресной
строки браузера, и продолжает работать даже без интернета (кроме самой первой загрузки).

## 🛠️ Изменить что-то под себя

- **Цвета и темы** — переменные `--primary`, `--sage`, `--amber` и другие
  в начале файла `css/style.css`.
- **Тексты и переводы** — файл `js/i18n.js`.
- **Набор эмодзи для аватара** — массив `EMOJI_SET` в начале `js/app.js`.
- **Диапазон лет в календаре** — константы `YEAR_MIN` / `YEAR_MAX` в `js/app.js`.

После любых изменений файлов — загрузите их заново на GitHub (**Add file → Upload files**,
или через `git push`, если вы уже работаете с Git локально), и сайт обновится
автоматически в течение минуты-двух.
